# Paradox Cleaner

Windows-утилита для подготовки игр Paradox Interactive к чистой переустановке при несовпадении контрольной суммы (checksum), конфликтах модов и повреждении пользовательских данных.

Интерфейс выполнен в стилистике глобальных стратегий: тёмная палитра, золотые акценты и отдельные панели для игр.

## Поддерживаемые игры

- Victoria 3
- Hearts of Iron IV
- Crusader Kings III
- Europa Universalis IV
- Stellaris

## Возможности

- Автопоиск стандартных Steam-библиотек и ручной выбор пути к отдельной установке.
- Выбор категорий очистки: игровые файлы, настройки и кеш, моды и данные лаунчера, Steam Workshop, сохранения.
- Предварительное сканирование и отображение точных путей.
- Безопасное перемещение найденных объектов в локальный архив вместо безвозвратного удаления.
- Журнал операций и восстановление без перезаписи существующих файлов.
- Сохранения в стандартных папках по умолчанию не включены в очистку.
- Пропуск ссылок и NTFS junction; общие данные Paradox Launcher не очищаются.

## Запуск

Требуется Windows 10/11 и Python 3.10 или новее с Tkinter (в стандартном установщике Python для Windows Tkinter включён по умолчанию).

```powershell
python ParadoxCleaner.pyw
```

Можно также открыть `ParadoxCleaner.pyw` двойным щелчком. Сторонние Python-пакеты не нужны.

## Как работает

1. Выберите нужную игру в верхней панели.
2. Для Steam оставьте поле пути пустым или укажите папку вручную. Для отдельной установки укажите корневую папку игры (например, `D:\Games\Victoria 3`).
3. Отметьте необходимые категории. Оставьте «Сохранения» выключенными, если хотите сохранить прогресс.
4. Нажмите «Найти файлы / Сканировать», проверьте список путей и предупреждения.
5. Закройте игру, Paradox Launcher и Steam, затем подтвердите очистку.
6. Установите игру заново. Запустите без модов и параметра `-debug_mode`, проверьте версию и checksum.

Для Steam предварительно отпишитесь от ненужных модов и при необходимости удалите игру через клиент, чтобы Steam не восстановил их автоматически. Облачная синхронизация может вернуть некоторые пользовательские файлы.

### Где программа ищет файлы

| Категория | Расположение |
| --- | --- |
| Установка | Ручной путь или `steamapps/common/<игра>` |
| Пользовательские данные | `Documents/Paradox Interactive/<игра>` (в том числе перенаправленные документы и OneDrive, если путь безопасен) |
| Данные игры в AppData | Папки с точным названием выбранной игры в `AppData/Paradox Interactive` |
| Steam Workshop | `steamapps/workshop/content/<AppID>` и соответствующий манифест |

### Архив и восстановление

Перед перемещением файлов создаётся журнал в `%LOCALAPPDATA%\ParadoxCleaner\history`. Сами объекты перемещаются в папки `.ParadoxCleaner_Backup_*` рядом с исходными каталогами на том же диске. Это позволяет убрать их из активных путей игры и при необходимости вернуть данные. Свободное место на диске при этом не увеличивается.

Чтобы вернуть файлы, откройте «История / Восстановить», выберите операцию и подтвердите восстановление. Программа не перезаписывает уже существующие файлы. После успешной переустановки можно вручную удалить ненужный архив, проверив, что в нём нет важных данных.

## Ограничения

- Программа не подменяет checksum и не модифицирует игровые файлы. Совпадение checksum зависит от версии, содержимого установленной игры, модов и параметров запуска.
- Не гарантируется обнаружение нестандартных путей, сторонних лаунчеров, облачных копий и нестандартных сохранений. Перед очисткой проверьте предпросмотр и архивы.
- Это независимый проект, не связанный с Paradox Interactive.
- Текущая версия — экспериментальная `v0.1`. Логика сканирования, архивирования и восстановления проверена на тестовых каталогах; полноценное тестирование интерфейса и файловых операций на Windows ещё требуется.
